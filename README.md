# Reinforcement Learning exercises at UVSQ et Paris-Saclay

Here is the content of the course in Reinforcement Learning at the University of Versailles Saint-Quentin, belonging to the one-year master's degree of Paris-Saclay in "Mathematics and Statistical Learning":

1) Dynamic Programming > Theory of Markov Decision Processes (MDP)
   
   - Value Function
   - Optimal Value Function and Bellmann Equation: algorithm of values iterations
   - Optimal Value Function: algorithm of policy iterations

2) Stochastic bandits > example of MDP

   - ETC(m) explore-then-commit algorithm
   - $\epsilon$-greedy and $\epsilon_{n}$-greedy decaying algorithm

3) Reinforcement Learning without model

   - MonteCarlo Algorithm for the estimation of the value function
   - MonteCarlo Algorithm $\epsilon$-greedy for the estimation of the optimal policy
   - TD(0) Algorithm, i.e. method of temporal differences, for the estimation of the optimal policy
   - Q-learning Algorithm 

------------

*For each topic, you will find an exercise sheet in Python.*
